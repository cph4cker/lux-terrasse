# Lux deck

Zen-terrasse med sandcirkel, naturpool og levende biofilter. Kundeside med plan, 3D-model, budget og stykliste.

- `index.html` – kundesiden (GitHub Pages)
- `BUDGET.md` – fuld stykliste og budget (danske priser, aug. 2026)
- `pool/PLAN.md`, `deck/PLAN.md` – konstruktion og byggerækkefølge
- `render/PROMPT.md` – prompt til visualisering
